# Product Glossary

This glossary defines technical terms, modules, and concepts used throughout the MapWork codebase.

---

## 📖 Key Terms

### 1. Geo-Intelligence
The integration of geographic data (coordinates, boundaries) with business data, allowing companies to make better decisions based on locations.

### 2. Micro-Zone (Or Geogrid)
Partitioning a city/region into sub-kilometer grids for sales team assignments.

### 3. Place ID
A unique text identifier associated with a coordinate map point (typically generated by maps API databases).

### 4. Route Planning
Calculating the shortest, most efficient route to visit multiple locations.

### 5. Hydration
The process where client-side JavaScript attaches event listeners to pre-rendered HTML in the browser.

### 6. SSR (Server Side Rendering)
Rendering React pages to HTML on the server before sending them to the browser, improving SEO and initial page load speed.

### 7. SSG (Static Site Generation)
Compiling pages to HTML files at build time, allowing them to be served instantly from CDNs.

### 8. Scroll Reveal
Fading assets or components into view as the user scrolls them into the viewport.
